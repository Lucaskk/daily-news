科技 / AI 方面，今天的重點不是新的單一 frontier model，而是「WWDC 實際發表與企業 agent 控制層」。Apple WWDC26 從昨天的 event watch 變成實際產品路線：Apple Intelligence rebuilt, App Intents for Siri AI, expanded Foundation Models framework, Core AI, and Xcode agents。OpenAI release notes 的新可用點包括 API generation requests moderation scores and Codex profile / appshot updates；Anthropic release notes 仍顯示 Claude enterprise custom-role permissions moving into governance；NVIDIA and LG announced an AI factory tying robotics, autonomous driving, GPU cloud and physical AI data generation；Microsoft's MAI page, updated June 8, clarifies seven in-house models, external developer distribution and Mayo Clinic health-model collaboration。
