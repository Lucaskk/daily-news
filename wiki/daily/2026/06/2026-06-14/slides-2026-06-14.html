Continuation · Anthropic

出口管制直接讓 frontier models 全球下線

命令範圍包含所有 foreign nationals

Anthropic 表示 6 月 12 日 17:21 ET 收到 directive。由於連員工也受限制，實務上只能對所有客戶停用 Fable 5、Mythos 5。

其他 Claude models 不受影響

停用是特定模型存取事件，而非 Claude 全線服務中止。恢復時間未定。

政府：jailbreak 可找出漏洞

政府提出 narrow jailbreak 與少量已知 vulnerabilities 作為風險理由。

Anthropic：技術標準不一致

公司稱未收到 universal jailbreak 或實際有害結果，且其他公開模型已有相近能力；在服從命令同時尋求恢復。

產品含義：模型能力、帳號資格之外，國籍與出口規則也開始成為 runtime access policy。

Model Lifecycle + Developer Controls

OpenAI 與 GitHub：升級也代表治理負擔

ChatGPT 退休 GPT-5.2 系列

GPT-5.2 Instant、Thinking、Pro 自 6 月 12 日不再於 ChatGPT 提供；既有對話遷移至對應 GPT-5.5。

官方公告只涵蓋 ChatGPT，不能推論 API 同步退休。

遷移會影響可重現性

舊對話繼續時模型行為可能改變；企業評估、提示測試與審計紀錄應保存模型版本與日期。

Copilot code review 組織級 runner

組織可統一設定 code review 與 cloud agent 的 runner type，降低 repository-by-repository 設定漂移。

內容排除與 instructions 擴張

Review 遵循 repo / org / enterprise exclusions；instruction files 移除 4,000 字元上限，但需管理規則衝突。

MCP + Disclosure

連接層擴張，消費者介面開始強制揭露

Smartsheet MCP 一套資料接三大助理

ChatGPT 支援摘要、狀態更新、Deep Research 與 Custom GPTs；Copilot 可透過 Studio 配到 Teams、Outlook、Word；Gemini 可在 Workspace 與 CLI 查詢 portfolio risks。

權限不是完全相同

Copilot 仍是 preview；Gemini 目前 read-only、未來才規劃 write access。各 connector 依 Smartsheet permissions 限制資料。

New York：AI 人物廣告必須標示

使用 AI 生成虛構人物的廣告，需清楚標示「synthetic performers」；法律已生效，未揭露可受處罰。

同一問題的兩端

MCP 處理系統如何取得資料；synthetic performer law 處理消費者如何知道內容由 AI 生成。兩者都把透明度變成產品介面。
