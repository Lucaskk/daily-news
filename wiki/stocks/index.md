# 股票分析索引

股票分析頁會放在 `wiki/stocks/YYYY/MM/YYYY-MM-DD/<stock-code>/`。

- [Latest Analysis](latest-analysis.html) - 最新一次產生的股票分析頁。

## 使用方式

LINE webhook 收到股票代碼或名稱後，會產生 HTML 分析頁並回傳短連結。完整內容放在網頁，LINE 只保留日期、標的與連結，以降低訊息長度與使用費用。
